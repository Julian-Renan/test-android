# 🎮 La Boîte à Jeux de Julian

Bienvenue sur le repository de mes petits jeux Android créés avec Android Studio ! C'est un projet personnel de retraité pour passer le temps et partager mes créations.

## 📱 Jeux disponibles

- **TAP TAP** - Appuyez aussi vite que possible !
- **REACTION TEST** - Testez votre temps de réaction
- **PUZZLE 3x3** - Résolvez des énigmes visuelles

## 📋 Informations techniques

- **Plateforme** : Android
- **SDK minimum** : 24 (Android 7.0)
- **Développeur** : Julian (amateur)
- **Type** : Passe-temps personnel

## 🚀 Installation

1. Téléchargez l'APK depuis la section **[Releases](../../releases)**
2. Installez le fichier APK sur votre appareil Android
3. Amusez-vous ! 🎯

### Prérequis
- Appareil Android avec minimum SDK 24
- Environ 15 MB d'espace disque
